\section{1. Descripción técnica-conceptual del proyecto a realizar}
\label{sec:descripcion}

La empresa Virtual Sense ofrece un servicio de monitoreo remoto de pacientes con enfermedades crónicas. Para este objetivo, la empresa posee una aplicación móvil que recolecta datos periódicamente, tales como presión arterial, saturación de oxígeno, glucemia, y otros indicadores de acuerdo a cada patología, desde dispositivos de medición vinculados a la plataforma. Estos datos son reportados a un sistema en el cual los profesionales médicos pueden acceder para realizar un seguimiento de los pacientes. Los pacientes, por su par parte, acceden también a contenido de consulta aprobado por su médico y a comunicación por chat con los profesionales.

La recolección periódica de mediciones permite el procesamiento de datos de manera continua, lo que a su vez posibilita la detección temprana y automática de arritmias cardíacas asintomáticas y otros eventos adversos. La empresa ha encontrado gran adopción por parte de médicos con pacientes que habitan lugares remotos, para los que es difícil o costoso la realización de visitas periódicas al consultorio. 

El stack de tecnología de la empresa consiste actualmente en una aplicación móvil que permite conectarse a diversos dispositivos (electrocardiógrafos, tensiómetros, etc). Esta aplicación reporta datos mediante protocolo HTTPS hacia Amazon Web Services y luego los datos son almacenados utilizando MySQL. Un panel de control web permite a los profesionales acceder a los datos de sus pacientes, así como a los pacientes acceder a sus propios datos. Este panel posee los permisos de acceso necesarios para que los usuarios solo puedan acceder a sus propios datos, y los profesionales accedan solamente a los datos de sus pacientes. En la figura \ref{fig:diagBloques} se describe brevemente el sistema implementado por la empresa para los dispositivos ya integrados.

\begin{figure}[htpb]
\centering 
\includegraphics[width=.65\textwidth]{./Figuras/Diagrama1.pdf}
\caption{Diagrama en bloques del sistema.}
\label{fig:diagBloques}
\end{figure}

La propuesta de trabajo realizada por Virtual Sense consiste en establecer una comunicación entre el sistema de la empresa y algunos dispositivos muy utilizados por los pacientes, pero para los cuales actualmente no poseen vinculación automática.  
Los tensiómetros de marca Omron son considerados dispositivos prioritarios por la empresa, dado su uso muy extendido entre los pacientes y la alta confiabilidad de las mediciones que producen. La empresa Omron ofrece varias opciones de integración de sus dispositivos, ya que pueden ser vinculados directamente mediante Bluetooth Low Energy a aplicaciones externas, o bien se puede realizar una vinculación a través de una API que permite comunicación entre la aplicación de Omron y aplicaciones externas. En base a estas opciones, se evaluará cuál es la estrategia de vinculación óptima para conectar los dispositivos a la aplicación de Virtual Sense, utilizando criterios como, por ejemplo, costo, posibilidad de mantenimiento posterior de la integración, tiempo de desarrollo y cantidad de modelos disponibles en el mercado para cada alternativa. Una vez definida la estrategia óptima para la vinculación del dispositivo, se implementará la vinculación para un dispositivo de la marca (a definir por la empresa).

\section{3. Propósito del proyecto}
\label{sec:proposito}

Lograr el envío automático de datos entre los dispositivos marca Omron y el servicio Virtual Sense. Esta funcionalidad tendrá un impacto positivo para los pacientes al evitar la carga manual de mediciones.

\section{4. Alcance del proyecto}
\label{sec:alcance}

El proyecto incluye:
\begin{itemize}
	\item Analizar las opciones de vinculación ofrecidas por Omron.
	\item Seleccionar la opción más conveniente para el sistema Virtual Sense.
	\item Implementar la vinculación seleccionada entre la aplicación Virtual Sense y un dispositivo Omron.
	\item Implementar el manejo de los datos en la nube:
	\begin{itemize}
		\item Realizar las modificaciones necesarias en la base de datos.
		\item Realizar las modificaciones en el panel de control.
	\end{itemize}
\end{itemize}

El proyecto no incluye la validación de esta comunicación en todos los dispositivos de la empresa ni el despliegue de esta funcionalidad en la versión de producción del sistema Virtual Sense.

\section{6. Requerimientos}
\label{sec:requerimientos}

\begin{enumerate}
	\item Requerimientos funcionales:
		\begin{enumerate}
			\item La aplicación de Virtual Sense se debe vincular con el dispositivo Omron.
			\item Los valores medidos por el dispositivo deben ser ingresados a la aplicación.
			\item El usuario debe poder consultar los valores medidos en la aplicación.
			\item Las mediciones se deben enviar a la nube, junto con la fecha y hora en la que se realizaron y la identificación del paciente.
		\end{enumerate}
	\item Requerimientos de documentación:
		\begin{enumerate}
			\item Generar las instrucciones de vinculación orientadas a los usuarios.
		\end{enumerate}
	\item Requerimiento de seguridad
		\begin{enumerate}
			\item Los datos se enviarán usando el protocolo actual de la empresa mediante HTTPS.
		\end{enumerate}
	\item Requerimientos de la interfaz en la aplicación.	
		\begin{enumerate}
			\item Se debe indicar el estado de la conexión con el dispositivo (conectado o desconectado).
			\item Se deben mostrar los valores obtenidos luego de una medición.
		\end{enumerate}
\end{enumerate}
